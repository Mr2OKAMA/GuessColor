# GuessColor

出題された1〜3色をすべて含むポケモンの名前を入力する、1人用のタイムアタッククイズです。正解するほど残り時間が伸びます。

> 非公式のファンメイド作品です。任天堂・ゲームフリーク・ポケモン社とは関係ありません。画像は使用せず、名前のテキストのみを扱います。

🎮 **プレイはこちら**: https://mr2okama.github.io/GuessColor/

## ルール
- 初期時間30秒、正解で残り時間が30秒まで回復、パスは-1秒（コンボ切れ）
- 不正解にペナルティはありません
- 問題は75%が1色、25%が2色。10コンボ(連続正解)ごとに3色の問題が出ます
- 画面の五十音キーで入力すると、ポケモン名の候補が表示されます。候補をタップするか、名前を最後まで入力して答えます

## データ
`src/data/pokemon.json` に `{ id, name, colors[] }` を追加します。色は 赤・青・黄・緑・黒・白・茶・ピンク・紫・灰・オレンジ から選びます。
図鑑番号1〜1025(全世代)を登録済みです。リージョンフォーム・メガシンカ・ゲンシカイキ・キョダイマックスと、見た目や色が変わる主なフォルムも別エントリとして登録しています(`id` は10001以降、`dex` に元の図鑑番号)。名前はフルネーム(例: `アローラライチュウ`)で答えます。
色違いは別エントリにせず、`shinyColors` に色を持たせています。通常の名前で答えるだけで、通常色・色違いのどちらの色でも正解になります。
第2世代以降の色は公式画像の配色とPokeAPIの色情報から自動推定したため、気になる箇所は随時修正してください。
